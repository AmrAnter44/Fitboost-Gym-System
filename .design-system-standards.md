# FitBoost Design System Standards

> Internal reference for UI/UX polish across all components and pages.
> Brand: yellow primary (#fbe003), data-dense dashboard, RTL + dark mode.

## 1. Anti-patterns to eliminate (search & replace)

| Anti-pattern | Replace with |
|---|---|
| Emoji icons (📊 🏠 💪 ✅ ❌ ⚠️ 🚪 🗑️ 👥 🔍 ⚙️ 📝 🔔 ➕ 🥗 🏥 🎯 💆 🧾 💸 💰) | Inline SVG (Heroicons outline style) `stroke="currentColor"`, `strokeWidth={1.8}`, `viewBox="0 0 24 24"` |
| `border-2 border-gray-200` heavy borders on cards | `ring-1 ring-gray-200 dark:ring-gray-700` + `shadow-sm` |
| `border-4 border-{color}-200` on dialogs | `ring-1 ring-{color}-200 dark:ring-{color}-900/50` |
| `transform hover:scale-105` on buttons (layout shift) | `transition-colors duration-200` only |
| `bg-black bg-opacity-50` backdrop | `bg-slate-950/60 backdrop-blur-sm` + `animate-backdrop-in` |
| `bg-white dark:bg-gray-800/20` (broken — missing `/` on light) | `bg-white/90 dark:bg-gray-800/20` |
| `animate-pulse bg-gray-200` skeletons | `skeleton-shimmer` class |
| `shadow-2xl` for ordinary cards | `shadow-sm` (cards) / `shadow-lg` (modals) / `shadow-xl` (popovers) |
| `text-gray-400` body text on light bg (low contrast) | `text-gray-600 dark:text-gray-400` |
| `bg-yellow-{500..700}` (off-brand) inside dialogs | `bg-amber-500` (for warning) or `bg-primary-{500..700}` (for brand) |
| `text-4xl` icon sizing via font-size | `w-7 h-7` SVG element |
| `transition` / `transition-all` (too broad) | `transition-colors duration-200` or `transition-[transform,opacity]` |
| Missing `aria-label` on icon-only buttons | Add `aria-label="..."` |
| `onClick` without `cursor-pointer` on `<div>` | Use `<button>` or add `role="button"` + `cursor-pointer` |

## 2. Standard tokens

### Cards / containers
```
bg-white dark:bg-gray-800 rounded-xl shadow-sm ring-1 ring-gray-200 dark:ring-gray-700 p-5
```

### Modals (overlay)
```
fixed inset-0 z-[10000] flex items-center justify-center p-4
bg-slate-950/60 backdrop-blur-sm animate-backdrop-in
```

### Modal panel
```
bg-white dark:bg-gray-800 rounded-2xl shadow-2xl max-w-{md|lg|xl} w-full
ring-1 ring-gray-200 dark:ring-gray-700 animate-modal-in
```

### Primary button (brand)
```
bg-primary-500 hover:bg-primary-600 text-gray-900 font-bold
px-4 py-2.5 rounded-lg transition-colors duration-200
focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary-500 focus-visible:ring-offset-2
dark:focus-visible:ring-offset-gray-900
disabled:opacity-60 disabled:cursor-not-allowed
```

### Secondary / ghost button
```
bg-gray-100 dark:bg-gray-700 text-gray-700 dark:text-gray-200
hover:bg-gray-200 dark:hover:bg-gray-600
px-4 py-2.5 rounded-lg transition-colors duration-200
```

### Danger button
```
bg-red-600 hover:bg-red-700 text-white
focus-visible:ring-red-500
```

### Form input
```
w-full px-3 py-2 rounded-lg border border-gray-300 dark:border-gray-600
bg-white dark:bg-gray-700 text-gray-900 dark:text-gray-100
placeholder:text-gray-400 dark:placeholder:text-gray-500
focus:outline-none focus:ring-2 focus:ring-primary-500 focus:border-transparent
transition-colors duration-200
```

### Form label
```
block text-sm font-bold text-gray-700 dark:text-gray-300 mb-1.5
```

### Table
```
<table className="w-full text-sm">
  <thead className="bg-gray-50 dark:bg-gray-900/40 text-gray-700 dark:text-gray-300 uppercase text-xs">
    <th className="px-4 py-3 text-start font-bold">
  <tbody className="divide-y divide-gray-100 dark:divide-gray-700/60">
    <tr className="hover:bg-gray-50 dark:hover:bg-gray-700/40 transition-colors">
      <td className="px-4 py-3 text-gray-700 dark:text-gray-300">
```

### Stat / KPI card
```
bg-white dark:bg-gray-800 rounded-xl shadow-sm ring-1 ring-gray-200 dark:ring-gray-700 p-5
  - <div className="text-xs font-bold uppercase tracking-wider text-gray-500 dark:text-gray-400">{label}</div>
  - <div className="mt-1 text-2xl font-bold text-gray-900 dark:text-gray-100">{value}</div>
  - icon: w-10 h-10 rounded-lg bg-primary-100 dark:bg-primary-900/30 text-primary-700 dark:text-primary-400
```

### Badge / chip
```
inline-flex items-center px-2.5 py-0.5 rounded-full text-xs font-bold
bg-{color}-100 dark:bg-{color}-900/40 text-{color}-700 dark:text-{color}-300
```

### Empty state
```
flex flex-col items-center justify-center py-12 text-center
  - SVG icon w-12 h-12 text-gray-400
  - h3 text-gray-600 dark:text-gray-300 font-bold mt-3
  - p text-sm text-gray-500 dark:text-gray-400 mt-1
```

### Loading
- Use `<LoadingSkeleton type="..." />` from `components/LoadingSkeleton`
- For inline spinner: `<svg className="animate-spin w-4 h-4" ...>` with the Heroicons "arrow-path"

## 3. Required a11y additions
- All icon-only buttons: `aria-label="..."`
- All modals: `role="dialog" aria-modal="true" aria-labelledby="..."`
- Active nav links: `aria-current="page"`
- Loading containers: `aria-busy="true" aria-live="polite"`
- Toggles/menus: `aria-haspopup aria-expanded`
- Escape key closes modals
- `autoFocus` on primary action of dialog

## 4. RTL must-haves
- Use logical properties: `start`/`end` instead of `left`/`right` (e.g. `me-2`, `ms-3`, `start-0`, `end-0`)
- Read `direction` from `useLanguage()` and pass `dir={direction}` to root
- For chevrons/arrows: rotate based on `direction === 'rtl'`

## 5. Standard SVG icon block (copy-paste header per file)
```tsx
const stroke = { fill: 'none', stroke: 'currentColor', strokeWidth: 1.8, viewBox: '0 0 24 24' } as const
```

## 6. Dark mode contrast requirements
- Background: `bg-white` → `dark:bg-gray-800` (or `dark:bg-gray-900` for outer)
- Borders/rings: `ring-gray-200` → `dark:ring-gray-700`
- Body text: `text-gray-700` → `dark:text-gray-300`
- Muted text: `text-gray-600` → `dark:text-gray-400`
- Headings: `text-gray-900` → `dark:text-gray-100`
- Surface elevations: `bg-gray-50` → `dark:bg-gray-900/40`
