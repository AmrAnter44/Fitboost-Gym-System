FitBoost — نظام إدارة الصالات الرياضية المتكامل
الإصدار 6.8.1

نظرة عامة
FitBoost نظام إدارة شامل للجيمات يغطّي كل احتياجات إدارة الصالة الرياضية:
- إدارة الأعضاء والاشتراكات
- خدمات تدريب متعددة (PT / تغذية / علاج طبيعي / كلاسات / سبا)
- نظام محاسبي وإيصالات احترافي
- تقارير وتحليلات مالية وتشغيلية
- واتساب مدمج بأكتر من رقم
- صلاحيات وأمان وتدقيق كامل
- شغّال أونلاين وأوفلاين

طريقة التشغيل (3 طرق)
1) تطبيق ديسكتوب على ويندوز (Setup.exe) باختصار سطح المكتب.
2) سيرفر محلي يفتح من أي جهاز على نفس الشبكة.
3) تطبيق ويب (PWA) يتثبّت على الموبايل والتابلت.

إدارة الأعضاء
- بيانات شخصية كاملة (صورة + صورتي البطاقة + رقم قومي)
- رقم عضوية فريد + باركود / QR
- تتبّع تاريخ بداية ونهاية الاشتراك
- تجميد الاشتراك بأيام محددة
- حظر العضو مع سبب، وحظر بأرقام التليفون والرقم القومي
- نظام نقاط مع تاريخ كامل
- تقييمات بدنية (وزن / نسبة دهون / كتلة عضلية)
- ساعات دخول مسموح بها لكل عضو
- باقات مجانية (PT / تغذية / علاج طبيعي / جروب / بول / بادل / InBody)

التدريب الشخصي (PT)
- إنشاء حزم تدريب بعدد جلسات وتعيين كوتش لكل عميل
- سحب جلسة بمسح QR من تطبيق العميل + توقيع رقمي على الجلسة
- عمولة الكوتش آلية مع كل جلسة + جدول كوتشز برسوم متدرّجة
- تجديد الحزمة + تاريخ كامل للجلسات (حضر / غاب)
- جلسات مجانية مرتبطة بباقات الأعضاء

الخدمات الإضافية (كل خدمة نظام مستقل بنفس البنية)
- التغذية: مع نسبة Referral للكوتش
- العلاج الطبيعي: جدولة جلسات + معالج مخصص
- الكلاسات الجماعية: جدول أسبوعي + حجز + حضور
- More: باقات مرنة + عمولات
- السبا: مساج / ساونا / جاكوزي بمواعيد
- Day Use: InBody واستخدام ليوم واحد
كل خدمة فيها: حزم + سحب جلسات + تجديد + تاريخ + عمولات + إيصالات.

الزوار والمتابعات (Sales Pipeline)
- تسجيل زائر مع المصدر (زيارة / موقع / ترشيح)
- مراحل: جديد ← تم التواصل ← تفاوض ← إغلاق
- تعيين متابعة لموظف سيلز + مواعيد اتصال وتذكيرات
- أولويات (عالي / متوسط / منخفض) ونشاطات (اتصال / واتساب / زيارة / ملاحظة)
- أرشفة عند التحويل لعضو + استيراد Leads من موقع الجيم
- تحليلات معدل التحويل

الموديول المالي
- إيصالات احترافية بترقيم آلي و7 أنواع
- طرق دفع متعددة (كاش / فيزا / انستا باي / محافظ) + تقسيم الدفعة
- إلغاء الإيصال بسبب ومعرفة مَن ألغاه
- طباعة + إرسال واتساب فوري
- مصروفات مصنّفة + شاشة إقفال يومي بأرقام اليوم

العروض والباقات
- مدة بالأيام (مرنة) + سعر وحد أدنى للسعر لمنع التخفيض الزائد
- جلسات مجانية من 8 خدمات + أيام تجميد مدمجة
- حدود ساعات دخول (مثلاً صباحي فقط) + نقاط بونص عند الترقية

الموظفين والموارد البشرية
- ملف موظف شامل: كود + مناصب متعددة + مرتب + ساعات عمل + شيفتات + إجازات
- حضور وانصراف ومدة الشيفت الفعلية + خصومات
- جدول دوريات أسبوعي (Rotations)
- عمولات بنظام شرائح أو نسبة ثابتة

نظام العمولات
- عمولات السيلز: تارجت شهري + 5 شرائح بنسب مختلفة + حساب آلي عند تسجيل عضو
- عمولات الكوتشز: عند كل جلسة + عند تسجيل عضو في باقة + Referral للتغذية والعلاج
- كل الإعدادات قابلة للتعديل من الأونر

الأمان والصلاحيات
- تسجيل دخول بإيميل وباسورد مشفّر + جلسات JWT + متابعة الجلسات الحية
- أكثر من 60 صلاحية على مستوى كل عملية (عرض / إضافة / تعديل / حذف) لكل موديول
- أدوار منفصلة (كوتش يشوف شاشات محدودة، سيلز يشوف متابعاته فقط)

التدقيق والمراقبة
- سجل تدقيق لكل عملية حساسة (مع المستخدم + الوقت + الحالة)
- تتبّع الأخطاء بتصنيف خطورة + سجل نشاطات لكل مستخدم

الواتساب المدمج
- أكتر من رقم في نفس الوقت + Inbox موحّد لكل المحادثات
- تعيين محادثات لموظفين + قوالب رسائل قابلة للتخصيص
- وضع تسخين للأرقام الجديدة + حد رسائل يومي لتفادي الحظر
- إرسال إيصالات وباركودز للأعضاء تلقائياً

التقارير والتحليلات
- لوحة رئيسية: إيرادات اليوم/الأسبوع/الشهر + أعداد الأعضاء النشطين والمنتهية
- زيارات الموقع + رسوم بيانية تفاعلية
- لوحة سيلز للمتابعات + تحليلات حضور + إحصائيات الكوتشز + سعة الجيم الحالية

نظام النقاط
- نقاط لكل حضور + على الدعوات + Referral + لكل جنيه يُدفع + نقاط عيد ميلاد تلقائية
- مهام تلقائية يومية: فحص أعياد الميلاد، إعادة فتح المتابعات، توزيع المتابعات، خروج تلقائي

الوضع الأوفلاين
- قاعدة بيانات محلية كاملة + طابور مزامنة للعمليات المعلّقة
- لما الإنترنت يرجع يتبعت كل شيء للسحابة (إيصالات / مصروفات / Leads)
- النتيجة: انقطاع الإنترنت ما يوقفش العمل في الجيم نهائياً

الترخيص (متعدد الفروع)
- اختيار الجيم والفرع عند التشغيل + التحقق من رخصة شغّالة
- قفل الشاشة عند انتهاء الرخصة + تحقق دوري

الواجهة وتجربة الاستخدام
- عربي + إنجليزي بالكامل (مع اتجاه RTL/LTR)
- وضع ليلي لكل مستخدم + ألوان ولوجو واسم الجيم مخصص
- بحث سريع + اختصارات لوحة مفاتيح + إشعارات + قوائم سريعة للبيانات الكبيرة

الإيصالات والطباعة
- إيصال احترافي قابل للتخصيص (لوجو + شروط وأحكام + روابط + QR للعضو)
- تصدير PDF و Excel + طباعة مباشرة + إرسال واتساب

الباركود و QR
- بطاقة عضوية بباركود/QR + سحب جلسة بمسح QR + Check-in سريع
- ماسح كاميرا مدمج + إرسال الباركود واتساب فوراً

أبرز المميزات التنافسية
- شغّال أوفلاين 100% — مفيش انقطاع شغل
- عربي + إنجليزي كامل
- يتعمله Install على ويندوز ويفتح من الموبايل كتطبيق
- واتساب مدمج بأكتر من رقم
- أكثر من 60 صلاحية مرنة لكل موظف
- أكثر من 40 جدول و100 مسار API
- سجلات تدقيق على كل حركة
- متعدد الجيمات والفروع بترخيص ذكي
- عمولات تلقائية بشرائح متدرّجة

الأرقام في سطور
- أكثر من 200 ملف كود
- أكثر من 40 جدول قاعدة بيانات
- أكثر من 100 مسار API
- أكثر من 60 صلاحية
- أكثر من 70 مكوّن واجهة
- منصات: ويب / ديسكتوب / موبايل
- لغتان: عربي + إنجليزي
- 8 خدمات مدعومة

حلول لكل دور
- الأونر: تقارير وأرباح وتحكم كامل
- الإدارة: صلاحيات وتدقيق ومراقبة
- الكوتش: جلسات + عمولات + عملاء
- الريسبشن: تسجيل دخول سريع + مبيعات
- العضو: تطبيق وباركود ونقاط
